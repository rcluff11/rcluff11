## Projects

### Notch: Habit Tracker & Planner
🔗 [Live site](https://notchedweb.netlify.app) · [Repo](https://github.com/rcluff11/habit-tracker)
- A "life operating system" that combines a time-blocked calendar, to-do list, daily habits, and personal rewards in one place. Plan your day on a 15-minute grid, check off tasks and habits to earn points, and track your weekly progress by category to see where you're crushing it and where you're slacking.
- Built with React (Vite) on the frontend and a self-hosted PocketBase backend running on a Google Cloud VM, with the frontend deployed on Netlify.
